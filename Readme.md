# Garden-100

Garden-100 is the index workspace for 100 small AI applications.

Each app lives under `app/<app-name>/` and keeps its own frontend, backend,
assets, local environment file, tests, and documentation. The repository root
stays lightweight so it can become the catalog and launcher for the full set of
apps.
