# Garden-100

Garden-100 is the index workspace for 100 small AI applications.

Each app lives under `app/<app-name>/` and keeps its own frontend, backend,
assets, local environment file, tests, and documentation. The repository root
stays lightweight so it can become the catalog and launcher for the full set of
apps.

## Apps

| # | App | Path | Status | Summary |
|---|-----|------|--------|---------|
| 001 | Language Coach | `app/language-coach` | MVP | Local reading-diagnosis tool for domain English materials. |
| 002 | FlowMate | `app/flowmate-macos-client` | MVP | Native macOS voice assistant with local streaming ASR and configurable shortcut phrases. |
| 003 | [Markdown Card — Native Floating Markdown Notes for macOS](https://github.com/lemontom0116-maker/markdown-card) | `app/markdown-card` | v0.1.1 | Native, always-on-top Markdown cards with rich editing, layouts, attachments, and CLI automation. |
